# Live Dashboard (GitHub Pages)

This project publishes the test dashboard to GitHub Pages so anyone can view it without access to your machine.

---

## ✅ One‑time setup
GitHub → **Repo Settings → Pages**

**Source = GitHub Actions** (recommended)

This repo deploys the dashboard via the workflow:
`.github/workflows/deploy-dashboard-pages.yml`

---

## ✅ Run tests (auto‑publish)
```bash
npm test
```

This will:
1. Run all tests
2. Generate the dashboard
3. Push updates to GitHub
4. Auto‑deploy GitHub Pages

---

## ✅ Live URL
```
https://saira-uwc.github.io/Shunyalabs_website/
```

## ✅ Dashboard UI & Structure

### Header
- Logo + title
- Last run timestamp
- Export dropdown (all runs / current run)
- Print button

### Tabs
- **Current Run**: summary + charts + module breakdown
- **Run History**: list of all runs with quick stats
- **Calendar View**: select a date to view runs that day

### Current Run Tab
- Summary cards: total, passed, failed, pass rate
- Charts: status donut + pass‑rate trend
- Module breakdown: per‑module pass/fail with test list

### Run History Tab
- Date‑grouped run cards
- Click a run to open **Run Details Modal**

### Run Details Modal
- Summary tiles
- Filter buttons (All / Passed / Failed)
- Full test list with:
  - Test point
  - Status
  - Category + module
  - Error details (with **View more** toggle)
  - Attachments (screenshots, videos, trace)
- Export this run (CSV/JSON)
- Print as proof

### Data Sources
- **Current run**: `test-results/*.csv` + `reports/json-report.json`
- **History**: `dashboard/history/runs.json`
- **Attachments**: `dashboard/playwright-artifacts/`
